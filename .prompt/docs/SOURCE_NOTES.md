# Source Notes

The hackathon-specific requirements in this documentation were derived from the supplied Bharat Agentic 2026 rules page.

Key requirements represented here:
- meaningful Agentic AI,
- real-world value,
- reasoning/planning/tool/API usage/multi-step workflows/actions,
- core project development during the 12-hour event,
- disclosure of significant pre-existing work,
- submission of project name, problem statement, solution overview, agent workflow/architecture, technology stack, repository, working demo, 2–3 minute video, and pitch deck,
- judging on agentic capability, relevance/impact, technical implementation, innovation, UX, scalability/feasibility, and demo quality,
- responsible AI constraints.

The AEGIS technical content is based on the supplied AEGIS Project Master Document and AEGIS Full Technical Specification. Where the hackathon implementation differs from the longer-term research architecture, this pack explicitly identifies the difference rather than silently blending them.
