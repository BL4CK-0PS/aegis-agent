# Submission copy (adapt to actual implementation)

**Name:** AEGIS — Autonomous Evidence-driven Governance and Intelligent Safety

**Domain:** Developer & AI (confirm organizer category)

**Problem:** Autonomous systems may encounter inconsistent sensor inputs such as GPS integrity degradation. Detecting an anomaly alone does not determine mission consequences or ensure that corrective actions are safe, authorized and effective.

**Solution:** AEGIS combines a tool-using AI agent with deterministic evidence, trust, mission-risk, simulation, policy, execution and verification services. In a controlled drone simulator, the agent investigates a GPS integrity incident, compares response options, requests authorization where required, and verifies or replans after execution.

**Agent workflow:** Observe → Reason → Tool Use → Evidence → Trust → Mission Impact → Simulate → Govern → Execute → Verify → Recover.

**Tech stack:** Python, FastAPI, Pydantic, OpenAI-compatible LLM tool calling, controlled deterministic drone simulator, React, TypeScript, Tailwind, Docker.

**Impact framing:** Demonstrates an auditable pattern for handling uncertainty and human oversight in autonomous systems. Do not claim deployment, safety certification, cost savings, or measured reliability unless demonstrated with evidence.

**Prior work disclosure:** AEGIS has a pre-existing research and specification foundation. The hackathon-scoped implementation and features developed during the event should be identified in the repository and submission. Third-party frameworks and models must also be acknowledged.

**Required:** GitHub URL, working demo, 2–3 min video, 5-slide deck, selected submission method, Google Form. Do not invent URLs.
